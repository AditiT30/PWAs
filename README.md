# PWAs
React PWA — Production Ready Progressive Web App

This project is a production-level Progressive Web App (PWA) built using React + Vite, designed to demonstrate real-world frontend engineering practices including offline support, caching strategies, installability, and service worker lifecycle management.

✨ Features

Installable web app (Add to Home Screen)

Offline support using service worker caching

App shell caching strategy

Service worker lifecycle handling (install, activate, update)

Cache versioning and update flow

Fast loading & performance optimized

Lighthouse PWA optimized

Clean UI and deployable architecture
